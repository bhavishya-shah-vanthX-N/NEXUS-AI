01 · RUNTIME ARCHITECTURE

How NexusAI Runs in Your Browser & on Local Servers

NexusAI has no external backend or cloud database. All HTML, CSS, and Vanilla JavaScript run directly inside Chrome or Microsoft Edge under the global window.NexusAI namespace.

STORAGE ENGINE · js/storage.js

IndexedDB (NexusAI_DB)

Your data lives inside the browser’s built-in IndexedDB database across 5 object stores: sources, readings, anomalies, settings, and datasets (with automatic LocalStorage fallback).

Important: Browsers isolate IndexedDB by origin. Data saved on http://127.0.0.1:5500 is separate from file:///D:/....

LIVE SYNC · js/data-manager.js

Validation & Event Bus

DataManager validates every source and reading before saving, then broadcasts CustomEvent notifications (nexusai:reading-added, nexusai:source-created, etc.) so charts, tables, and counters refresh automatically.

Updating a source’s name or thresholds preserves existing reading history cleanly.

ORIGIN MODES

http://localhost vs. file://

Serving via VS Code Live Server (http://localhost) marks the page as a Secure Context, unlocking Web Serial, Web Bluetooth, and multi-thread Web Worker CPU benchmarks. Opening via file:// disables those browser APIs and falls back to single-thread CPU benchmarking.

02 · COMPLETE PLATFORM TOUR

Every Page, Button & What It Does

How the 7 pages connect together into one end-to-end monitoring workflow.

1. Dashboard (index.html · js/main.js)

  • Monitoring Sources: Total configured sources and how many are currently active.
  • Telemetry Readings: Total count of stored records in IndexedDB readings.
  • Active Alerts: Warning + critical events recorded in anomalies.
  • Platform Status: Shows READY when IndexedDB and DataManager boot cleanly, or ERROR if storage initialization fails.

2. Monitoring Workspace (workspace.html · js/workspace.js)

  • Add / Edit Source: Pick a Device Type preset (Laptop, Server, NPU Node, GPU Node, Robotic Arm, Cooling Unit, Sensor, or Custom) and architecture (ARM64, x64, x86).
  • 6-Column Metric Builder: Define unique metric names, units, Warning, Critical, and Enable toggles.
  • Bidirectional Thresholds: If Critical > Warning (e.g., 90°C > 75°C), high values trigger alerts. If Critical < Warning (e.g., 12% < 25% Battery or 20 < 40 FPS), low drops trigger alerts.
  • Manual Entry & Import/Export: Add single MANUAL points, import CSV/JSON, or export full workspace backups.

3. Live Telemetry (telemetry.html · js/telemetry.js)

  • + Register This Laptop: Auto-creates a Local Laptop (Real Browser Telemetry) source containing only the real metrics your browser actually exposes.
  • ▶ Stream Real Host: Records live DEVICE readings at the source’s sampling interval (Battery %, JS Heap %, Network RTT/Downlink, UI Render FPS, Main Thread Jitter).
  • ▶ Start Live Simulation / ⚡ Inject Spike / +1 Sample: Generates synthetic SIMULATED readings for testing charts and threshold breaches safely.
  • Filters & Chart: Filter by Source, Metric, Time Window (All, 15m, 1h, 24h), and Input Mode, hover points on Canvas, and inspect the live Alert Feed.

4. AI Analytics (ai-analytics.html · js/ai-engine.js)

  • ⚡ Run Z-Score Scan: Recomputes rolling Z-score outliers, OLS regression + 95% PI cone, Student’s t 95% CI, Welch shift test, health breakdown, and plain-English cards.
  • Origin Filter: Isolate DEVICE from SIMULATED, MANUAL, or IMPORT so test spikes never distort real laptop diagnostics.
  • Save Outliers to Alert Log: Persists detected statistical Z-score outliers into IndexedDB anomalies so they appear in Alert Feeds across pages.
  • What-If Sliders & Export Report JSON: Preview threshold headroom (70%–130%) and rolling window size (10–100) without modifying saved configs, or download the full JSON report.

5. Hardware Gallery (hardware.html · js/gallery.js)

  • Compares 8 published REFERENCE SPEC edge platforms (Snapdragon X1-26-100, Jetson Orin Nano Super, Raspberry Pi 5 + Hailo-8L, Coral Edge TPU, ESP32-S3, RTX 4070, 6-DOF Robotic Arm, Rack Cooling Unit) alongside your live detected host card.
  • Includes search, category/architecture/sort filters, a Canvas TOPS vs. TOPS/W chart, and + Add to Workspace provisioning inside each detail modal.

6. External Hardware Connectors (js/device-connectors.js)

  • Web Serial: Connects USB microcontrollers (Arduino, ESP32) at 115200 / 9600 / 57600 baud. Understands JSON ({"metric":"Temp","value":41.2}), key:value, key=value, or plain numeric lines.
  • Web Bluetooth: Pairs BLE GATT devices and polls standard Battery Service (0x180F) every 5 seconds when exposed.
  • WebSocket: Connects any local OS agent at ws://localhost:8765 (or custom ws:// / wss://) pushing real sensor payloads.

04 · COMPUTE POWER NUMBERS

How CPU, GPU & NPU / ML Benchmark Scores Are Calculated

When you click ⚡ Run CPU / GPU / NPU Benchmark on Live Telemetry, NexusAI runs real workloads in your browser and converts measured throughput into dimensionless rating scores:

Per-Subsystem Workloads & Formulas

  • CPU Compute Rating (40% Weight): Launches 1 Web Worker per logical core (up to 16). Each worker runs 2,500,000 floating-point multiply + Math.sqrt() iterations (4 ops/iter = 10M ops/core).
    Formula: MOPS = totalOps / avgWorkerMs / 1000, then Score = round(MOPS × 85).
    On file://: Runs 6,000,000 iterations on 1 main thread and scales via MOPS × 110.
  • GPU Shader Rating (35% Weight): Creates a 512×512 WebGL2 canvas, compiles a GLSL fragment shader running 48 Mandelbrot complex-plane ALU loops per pixel across 1 warmup + 24 timed passes (6,291,456 shader pixels total), synchronized with gl.finish().
    Formula: MPix/s = totalPixels / (elapsedMs / 1000) / 1e6, then Score = round(MPix/s × 12).
  • NPU / ML Inference Rating (25% Weight): Checks navigator.ml.createContext({ deviceType: "npu" }) (WebNN), then benchmarks 180 passes of 48×48 dense matrix multiplication + ReLU activation.
    Formula: Score = round(infPerSec × 12), displaying throughput in inf/s, average latency in ms/inf, and raw compute in GOPS.
  • Edge Readiness Rating (Overall): 0.40 × CPU + 0.35 × GPU + 0.25 × NPU.

How to Read Score Tiers & Output Readings

8,000+
Flagship / Workstation

High multi-core throughput, strong GPU shader fill rate, and fast matrix inference headroom.

4,500 – 7,999
High Performance

Modern ultrabook/ARM64/discrete-class laptop performance well suited for local edge workloads.

2,200 – 4,499
Balanced Edge

Typical battery-efficient mode, thin client, or single-thread fallback run on file://.

< 2,200
Entry / Low-Power (or 0 = Unavailable)

Power-saver throttling, background CPU contention, or WebGL disabled (0).

Tip: For accurate comparative numbers, plug in AC power, close heavy background tabs, and run on http://localhost so multi-worker CPU passes activate.

05 · STATISTICAL INFERENCE MODELS

How the AI Analytics Engine Thinks & What Every Output Means

js/ai-engine.js computes formal classical statistical inference locally in your browser (zero neural-network black boxes). Here is every model, chart line, and diagnostic card:

1. Rolling Z-Score & Outlier Detection

Measures how unusual each reading x is compared to the trailing baseline of up to 20 previous samples (mean μ, sample standard deviation σ): 

Z = (x − μ) / σ
  • Sensitivity Options: 1.5σ (Strict early warning), 2.0σ (Balanced default), 2.5σ (Moderate), 3.0σ (Extreme spikes only).
  • Severity Rules: Marked WARNING if |Z| ≥ threshold, and upgraded to CRITICAL if |Z| ≥ threshold + 1.0 or the configured critical bound is breached.
  • On the Chart: Blue line = Actual readings; shaded band = μ ± Z·σ control envelope; red dots = Outliers.

2. Student’s t 95% Confidence Interval (CI)

Instead of showing only a single sample average, NexusAI computes the 95% Student’s t confidence interval using exact incomplete Beta & Lanczos Gamma CDF math in pure JS: 

95% CI = x̄ ± t* · (s / √n),   df = n − 1
  • Example Card: "True population mean estimated at 4.25 ± 1.47 ms" with "[2.77, 5.72] across n=27 samples (df=26, t*=2.06)".
  • Meaning: Based on your 27 readings (with 26 degrees of freedom and critical t* = 2.06), we are 95% confident the true underlying mean latency is between 2.77 ms and 5.72 ms. More samples (larger n) shrink the margin of error!

3. OLS Linear Regression, Slope t-Test & 95% PI Cone

Fits Ordinary Least Squares (ŷ = a + b·t) across your sample window and tests whether the trend slope b is statistically real or just random noise:

  • R² Fit (0.00 – 1.00): Share of variance explained by time. Near 1.00 = strong directional trend; near 0.00 = mostly flat/noisy readings.
  • Slope Hypothesis Test (t = b / SE(b), p-value): If p < 0.05, the upward/downward drift is statistically significant rather than random jitter.
  • Purple Forecast Zone & 95% PI Cone: Dashed purple line projects the next 5/10/15 steps, while the shaded cone shows the 95% Prediction Interval where individual future readings are likely to land (widening further out).
  • Est. Threshold Breach: Estimates how many sampling intervals remain before the regression line hits your Warning/Critical limit (or reports Stable / Moving away from limit / Breached now).

4. Welch’s t-Test, Health Score & What-If Preview

  • Welch’s Two-Sample Shift Test: Splits the window into an older half and recent half (without assuming equal variance). If p < 0.05, it flags a statistically significant baseline shift (e.g., sudden thermal creep or workload change).
  • Rule-Based Health Score (0–100):
    Score = 100 − (breachRate × 55) − (outlierRate × 35) − min(20, CV × 35)
    Green HEALTHY (82–100), Amber DEGRADED (60–81 or warning breach), Red CRITICAL (<60 or critical breach).
  • What-If Sensitivity Preview: Moves simulated warning limits between 70% and 130% and rolling window size (10–100) in memory only—helpful for tuning noisy alert thresholds safely.

Both Workspace’s full CSV export and Telemetry’s filtered CSV export write UTF-8 with BOM (\uFEFF) so Excel renders °C cleanly. Exact 8 columns: 

sourceId,sourceName,metricId,metric,value,unit,timestamp,inputMode
source_abc,Local Laptop,metric_1,Main Thread Jitter,4.25,ms,2026-11-28T10:15:00.000Z,device

Re-importing CSV: Matches existing sources by sourceId or sourceName and metrics by metricId or metric. Rows with non-numeric values or unmatched sources/metrics are safely skipped, and valid rows are tagged IMPORT.

08 · BROWSER BOUNDARIES & TROUBLESHOOTING

Browser Security Limits & Frequently Asked Questions

Why certain OS hardware metrics behave differently in web browsers and how to troubleshoot common outputs.

Why can’t NexusAI read OS CPU %, NPU %, or CPU/GPU °C temperature directly?

Browsers enforce strict OS sandboxing so websites cannot read kernel counters (WMI, PDH, Linux hwmon, or NVIDIA NVML). Rather than inventing fake CPU% or °C numbers, NexusAI reads only genuine browser APIs or external Serial/BLE/WebSocket sensors. Native OS telemetry agents (Rust + C++) are detailed in Development Roadmap.

My Bluetooth earbuds/headset connected via Web Bluetooth, why was no battery value logged?

Web Bluetooth only reads standard BLE GATT services like Battery Service (0x180F). Consumer earbuds often transmit battery levels over proprietary Bluetooth Classic/vendor channels, which browsers cannot access. Microcontrollers (ESP32, nRF52) or BLE sensors advertising GATT 0x180F log battery readings automatically every 5 seconds.

Why does AI Analytics say “Need at least 5 readings” or show wide Confidence Intervals?

Rolling Z-score, OLS slope tests, and Student’s t intervals require at least 5 samples (and ideally 15–30+) to estimate variance reliably. Stream your laptop for 20–30 seconds on Live Telemetry (or run a Simulation) and click Refresh on AI Analytics to watch the 95% interval tighten.

Why were some rows skipped during CSV import?

In workspace.js, a CSV row is skipped if: (1) value is missing or not a finite number, (2) neither sourceId nor sourceName matches an existing source in Workspace, or (3) neither metricId nor metric matches an enabled metric on that source. Use Workspace Export JSON when transferring both sources and readings together to a new browser.
